# Glossario Arquitetural

Esta pasta registra o vocabulario arquitetural oficial do produto MES/MOM.

## Proposito

O glossario arquitetural consolida termos usados em Architecture Sessions, Decision Logs, roadmap e demais documentos tecnicos do Project Book.

## Documento principal

- `Glossario Arquitetural do MES.md`

## Regra de governanca

- O glossario nao substitui Architecture Sessions.
- O glossario nao substitui Decision Logs.
- O glossario nao cria novas decisoes arquiteturais.
- Novos conceitos relevantes devem nascer primeiro em discussao e Architecture Session apropriada.
- O glossario deve ser atualizado apenas para consolidar conceitos ja discutidos, aprovados ou explicitamente planejados.
